# koishi-plugin-huaji-meme

群聊梗词绑定机器人。把一段文字或一张图片与关键词绑定，之后群里有人提到这个关键词，机器人就自动把内容发出来。

- 任何群成员都能创建自己的梗词，**默认只能管理自己创建的**
- 管理员可管理全群所有梗词
- 全部配置在 Koishi 插件配置面板上完成
- 适配器无关：官方 QQ 机器人、napcat、onebot 等均可使用

## 安装

在 Koishi 控制台 → **插件市场** 搜索 `huaji-meme`，点击安装。

或使用命令行：

```bash
# 官方 QQ 机器人
npm install koishi-plugin-huaji-meme

# 配套数据库插件（若尚未安装）
npm install @koishijs/plugin-database-memory
```

> 本插件依赖 `database` 服务。若你的 Koishi 尚未安装任何数据库插件，需要先装一个（如 `@koishijs/plugin-database-memory`）并启用，否则插件无法启动。

安装完成后在 **插件配置** 列表中找到 `huaji-meme`，按需调整配置项即可使用。

## 配置连接器

本插件不绑定任何特定连接器，你只需保证机器人能收到群消息即可。**推荐优先级**：

| 连接器 | 群消息接收能力 | 自动触发体验 |
| --- | --- | --- |
| `koishi-plugin-adapter-onebot`（NapCat / Lagrange 等） | 收到**全部**群消息 | ★★★★★ 完美，任何人说话都能触发 |
| `adapter-qq` / `@koishijs/plugin-adapter-qq`（官方 QQ 机器人） | **只能收到 @机器人 的消息** | ★★☆☆☆ 需 @机器人 才能触发 |
| `koishi-plugin-adapter-telegram` 等 | 视平台而定 | 一般 |

### 使用官方 QQ 机器人（adapter-qq）

1. 前往 [QQ 开放平台](https://q.qq.com) 创建机器人，在「开发设置」获取 `[id, token, key]`
2. Koishi 中安装并配置 `adapter-qq`：
   - `机器人类型（type）`：公域选 `public`
   - 填入上面三项数据（注意**顺序与后台不同**）
   - `intents`：在 QQ 群中使用需勾选 `USER_MESSAGE`，`MESSAGE_AUDIT` 为必勾
   - 不要勾选「开启沙箱模式」
3. 在 QQ 开放平台「沙箱配置」里添加要测试的 QQ 群，并在手机 QQ 群设置 → 群机器人 中添加该机器人
4. 回到 Koishi，点右上角 ▶️ 启动，右下角状态灯变绿即连接成功

**重要**：官方 QQ 机器人在群聊中**只会推送 @机器人 的消息**（事件 `GROUP_AT_MESSAGE_CREATE`），这是平台限制，插件无法绕过。详见[平台限制](#平台限制与注意事项)。

### 使用 NapCat / OneBot

安装 `koishi-plugin-adapter-onebot`，在 NapCat 端开启 **正向 WebSocket** 服务，填入地址即可。用 NapCat 时机器人能收到全部群消息，梗词可以做到「有人说话就自动接梗」。

## 插件配置

在 Koishi 控制台 → 插件配置 → `huaji-meme`，共 14 项：

### 权限相关

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `adminList` | `string[]` | `[]` | **管理员 QQ 号列表**。填写后这些号码即为管理员，可管理所有梗词。留空则仅 Koishi 权限等级 ≥3 的用户为管理员 |
| `userBlacklist` | `string[]` | `[]` | **用户黑名单**。命中的用户所有操作均被静默忽略（不会有任何回复） |

### 群/频道范围

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `groupWhitelistEnabled` | `boolean` | `false` | 是否启用群/频道白名单 |
| `groupWhitelist` | `string[]` | `[]` | 白名单群号/频道号。**开启白名单后，此列表为空的群一律不可用** |
| `allowPrivateChat` | `boolean` | `true` | 是否允许私聊使用。私聊下只能管理自己创建的词条，且**不会触发**梗词 |

### 触发控制

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `autoTrigger` | `boolean` | `true` | **自动触发总开关**。关闭后仅指令可用，不会自动发送梗词 |
| `requireAt` | `boolean` | `false` | 是否必须 @机器人 才触发。官方 QQ 机器人请保持 `false`（平台本就只推 @ 消息） |
| `matchMode` | `'fuzzy' \| 'exact'` | `fuzzy` | 匹配模式。`fuzzy`=消息中出现关键词即触发；`exact`=整条消息与关键词完全相同才触发 |
| `cooldownSeconds` | `number` | `10` | 冷却秒数。同一群内相同关键词的重复触发间隔，`0` 表示不限制 |
| `atSenderOnTrigger` | `boolean` | `false` | 触发时是否 @ 触发者。部分连接器不支持回复内 @ |

### 配额限制

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `maxTotalEntries` | `number` | `0` | 全平台词条总数上限，`0` 表示不限制 |
| `maxUserEntries` | `number` | `20` | 单个用户可创建的词条数上限，`0` 表示不限制 |
| `maxKeywordLength` | `number` | `20` | 关键词最大字符数 |
| `allowEdit` | `boolean` | `true` | 是否允许用户编辑自己创建的词条 |

## 指令一览

### 用户指令

| 指令 | 说明 |
| --- | --- |
| `添加梗 <关键词> <内容>` | 绑定一段文字。内容可含空格 |
| `添加梗图` | 交互式：按提示发图 → 再回复关键词 |
| `添加梗图 <关键词>` | 直接带关键词，随后发图即可 |
| `编辑梗 <关键词>` | 修改自己绑定的内容（文字/图片均可）；有多个同名词条时会让你选序号 |
| `删除梗 <关键词>` | 删除自己创建的该关键词全部内容 |
| `我的梗` | 查看自己创建的所有词条 |
| `梗列表` | 查看本群所有词条 |
| `梗帮助` | 玩法与指令说明 |

### 管理员指令

管理员 = `adminList` 中的号码，或 Koishi 用户权限等级 ≥3。

| 指令 | 说明 |
| --- | --- |
| `管理梗列表` | 查看本群所有词条，附带 id 与创建者 |
| `管理删除 <关键词> [序号]` | 删除任意用户的词条。不带序号则删除该关键词全部内容 |
| `管理清空` | 清空本群所有梗词 |
| `管理设置 <项> <值>` | 运行时改配置。项为 `自动触发` / `必须@`（值填`开`或`关`）、`匹配模式`（值填 `fuzzy` 或 `exact`） |

## 玩法示例

```
你 >> 添加梗 233 你干嘛哎哟
机器人 << 已绑定文字梗：说到「233」时我会回：你干嘛哎哟

你 >> 添加梗图 猫猫
机器人 << 请在 2 分钟内直接发送图片（可附带任意说明文字）。
你    << [发一张猫猫图]
机器人 << 图片已收到！请回复这个梗的关键词（不含空格）。
你    >> 猫猫
机器人 << 已绑定图片梗：说到「猫猫」时我会发这张图

群友 >> 今天的233太离谱了
机器人 << 你干嘛哎哟

群友 >> 猫猫
机器人 << [发出猫猫图]
```

**多个内容绑同一关键词**：允许存在多条，触发时**随机**抽一条。比如三个人分别给「233」绑了三张不同的图，群里每次有人说 233 都会随机收到其中一张。

**按群隔离**：词条以「群号 + 关键词」为维度存储。A 群绑定「猫猫」不会影响 B 群。

## 权限模型

**普通用户**
- 可以创建、查看、删除**自己**创建的词条
- 可以查看本群所有人的词条列表（但看不到他人内容的编辑入口）
- 尝试删除他人词条会被拒绝
- 达到配额上限后无法继续创建

**管理员**（`adminList` 或 authority ≥ 3）
- 可以删除、修改**任何**用户的词条
- 可以清空本群所有梗词
- 可以在运行时调整触发相关配置

**被拦截的情况**（均为静默，无任何回复）
- 不在白名单内的群
- 命中用户黑名单的用户

## 平台限制与注意事项

### 官方 QQ 机器人的硬性限制

这是使用官方 QQ 机器人时**必须了解**的部分，非插件问题：

| 限制 | 具体表现 | 应对方式 |
| --- | --- | --- |
| **收不到非 @ 消息** | 群聊只推送 `GROUP_AT_MESSAGE_CREATE`，即只有 @机器人 的消息才会到达插件 | 用 NapCat/OneBot 可获得完整体验；或接受「@机器人 + 关键词」的用法 |
| 主动消息每月限额 | 主动消息每月每群仅 **4 条** | 尽量让用户先 @ 再触发，走被动回复通道 |
| 被动回复频率限制 | 被动消息有效期 **5 分钟**，最多回复 **5 次** | 插件的 `cooldownSeconds` 冷却机制已默认开启（10s），可有效避免超频 |
| 沙箱限制 | 未通过审核的机器人只能与沙箱配置中的群/用户交互 | 开发阶段在后台「沙箱配置」中添加测试群 |

**结论**：官方 QQ 机器人上，`autoTrigger` 和 `requireAt` 请都保持默认 `false` —— 平台层面就决定了只能 @ 触发，改这两个配置不会有额外效果，也不会造成故障。想要真正的「自动接梗」，请使用 NapCat 等 OneBot 实现。

### 图片相关

- 图片通过读取用户**实际发送的消息元素**获取，因此用户必须真的在群里发一张图（不能只发图片链接）
- 各平台产出的图片标识不同（`file://`、临时 URL、fileId 等），插件原样存储、原样发送，在同一平台内可正常工作
- 跨平台迁移时（如从 NapCat 换到官方 QQ），已存的图片标识可能失效，需要让用户重新绑定图片

### 存储

- 词条存于数据库表 `huaji_meme`
- 冷却计数存于**内存**，重启后清零（不影响正确性）
- 换数据库或迁移服务器时请备份该表

## 常见问题

**Q：配置了白名单，群里用不了？**
A：检查 `groupWhitelistEnabled` 是否为 `true`，以及 `groupWhitelist` 是否包含目标群号（填纯数字，不带任何前缀）。注意**白名单开启后，列表外的群全部不可用**。

**Q：谁算管理员？**
A：两种方式任一命中即为管理员：① `adminList` 里的 QQ 号；② Koishi 用户权限等级 ≥3（在 Koishi 用户管理里设置）。推荐用 `adminList`，不依赖 Koishi 权限体系。

**Q：为什么我说关键词机器人没反应？**
A：按顺序排查：
1. `autoTrigger` 是否为 `true`（总开关）
2. 群里是否真的出现了该关键词（`exact` 模式下必须整条消息完全等于关键词）
3. 是否被 `cooldownSeconds` 冷却了
4. 若用官方 QQ 机器人：必须 @机器人 才能触发
5. 群里是否在 `groupWhitelist` 内

**Q：`添加梗 233 你干嘛哎哟` 报错？**
A：请确认格式 —— 关键词与内容之间用**空格**分隔，关键词本身不能含空格。内容可含空格。

**Q：能删除别人创建的梗词吗？**
A：普通用户不能，这正是本插件的权限设计。管理员可以用 `管理删除` 强制删除。

**Q：换连接器后词条还在吗？**
A：词条按 `platform:uid` 存储 userId。更换连接器（如 NapCat → 官方 QQ）会导致用户 ID 前缀变化，已有词条的「创建者」可能对不上，但**词条内容与触发不受影响**。只有需要精确管理归属时才需注意。

**Q：报 `property meme is not registered` / `missing primary key`？**
A：请确认安装的是本插件的正式版本（`npm list koishi-plugin-huaji-meme`），而不是某个半成品分支。
